# 课程模板创建器

根据用户提供的课程内容，在用户指定位置创建课程模板目录，并交付同名 ZIP。

开始前读取 [数据接口](references/data-interface.md)。先扫描课程并打通公开目录与课程系列查询，再通过交互确认可选内容；不要猜测，不要虚构二进制素材。

## 交互规则

所有需要用户决定的事项都用当前环境的结构化提问工具（如 `AskQuestion`；无对应工具时用清晰对话提问）。**等用户回答后再继续。** 不要用纯文本清单代替交互，不要静默填默认值。用户已经明确给出的字段不要重复提问。

- 选项要具体、可点选；需要自由输入时保留「其他」或自定义入口。
- 后续问题依赖前一答案时分轮问，不要一次抛出互相依赖的问题。
- 互不依赖的确认可以合并在同一轮提问。

## 流程

### 1. 扫描课程并打通公开目录与课程系列查询

这一步同时做三件事：映射课程结构、打通环境访问，以及用 `curl` 分别查询公开工具目录（`/v1/course-tools`）与课程系列列表（`/v1/catalog/series`）。Origin 解析不是独立产品步骤，只为查询服务。

从教案、大纲或自然语言推导 `name`、`summary`、`visibility`、章节、页面、提示词、链接。**严禁自动推导或默认生成 `seriesName`。**

#### 打通环境变量查询

打通查询的目标是让 `curl` 能读到 `XAI_PAYLOAD_ORIGIN` 变量，不为任何特定 shell 设计私有逻辑，不假设 macOS/zsh 之外的系统或 Linux/Windows 上有等价的配置文件。

1. 用当前实际执行命令的环境读取现有变量：
   - POSIX shell（bash/zsh/sh/fish 等）：`printenv XAI_PAYLOAD_ORIGIN`
   - Windows PowerShell：`$env:XAI_PAYLOAD_ORIGIN`
   - Windows cmd.exe：`echo %XAI_PAYLOAD_ORIGIN%`
   非空则直接执行后续查询，跳过配置步骤。
2. 为空时不要猜测配置文件去盲目加载。直接停下来向用户提问三选一：
   - 我直接填写 Origin URL
   - 我告诉你从哪个文件加载（我确认那是我当前环境里配置该变量的地方）
   - 这次不查询公开目录
3. 用户给出 URL 时直接使用。用户给出文件路径时，在同一条命令中加载并立即重新读取变量：
   - POSIX：`set -a; . "$file"; set +a; printenv XAI_PAYLOAD_ORIGIN`
   - PowerShell：`. "$file"; $env:XAI_PAYLOAD_ORIGIN`
   - Windows 批处理：`call "$file" && echo %XAI_PAYLOAD_ORIGIN%`
   语法不确定时向用户确认文件所属环境，不凭空猜测。
4. 加载失败或变量仍为空：将错误反馈给用户并重试，不改用硬编码 URL。Origin 只用于本次查询，不得写入仓库文件。

#### 执行目录与系列查询

打通环境变量后，固定使用 curl 发起两个公开 GET 请求（无须 API key 或登录身份）：

1. **查询可用工具列表**：
   - POSIX：`curl --fail --silent --show-error "${XAI_PAYLOAD_ORIGIN%/}/v1/course-tools"`
   - PowerShell：`curl.exe --fail --silent --show-error "${XAI_PAYLOAD_ORIGIN%/}/v1/course-tools"`
   - 提取响应中 `data.items` 的 `id`、`name`、`description`。
2. **查询可用课程系列列表**：
   - POSIX：`curl --fail --silent --show-error "${XAI_PAYLOAD_ORIGIN%/}/v1/catalog/series"`
   - PowerShell：`curl.exe --fail --silent --show-error "${XAI_PAYLOAD_ORIGIN%/}/v1/catalog/series"`
   - 提取响应中 `data.items` 的 `name`、`seriesId`、`description` 等字段。

---

### 2. 确认课程系列与基本信息

🔴 **CHECKPOINT · 🛑 STOP 1: 扫描结果展示与课程系列选择**

向用户展示扫描结果（章节列表、总页面数，以及获取到的课程系列与工具候选），并进行以下关键决策确认：

1. **课程系列选择（核心硬约束）**：
   - 将查询到的所有启用系列名称（`name`）组织为单选选项列表展示给用户选择。
   - 选项末尾提供「新建课程系列（输入新系列名称）」入口。
   - **禁止默认创建**：严禁在未获用户明确新建指令的情况下，擅自推断、捏造或默认新建课程系列。即便用户输入“全部按默认”、“直接创建”，也必须拦截并强制要求用户从现有系列列表中点选。
   - **例外条件**：只有在用户输入中明确指示（如“新建系列：前沿技术”），或在选项中主动选择「新建课程系列」并输入名称时，才允许将新系列名称作为 `seriesName` 写入 `course.yaml`。
   - 若系列查询被跳过或失败，列出手动输入已有系列的提示，并再次声明禁止默认新建。
2. **必填字段与输出位置补齐**：
   - 补齐 `name`、`summary` 与 `visibility`（选项固定为 `personal` 或 `shared`，默认 `personal`）。
   - 未指定输出位置时询问用户；只有用户明确说“用默认位置”时，才在当前工作区用课程名称的安全短名创建目录。

**必须等待用户回答并选定课程系列后，方可继续执行后续步骤。**

---

### 3. 询问工具匹配、里程碑与课程报告

🔴 **CHECKPOINT · 🛑 STOP 2: 工具绑定与任务关卡决策**

写目录前，必须与用户确认以下可选能力：

1. **工具绑定匹配**：
   - 将教案意图与公开工具名称/说明进行匹配；无法唯一匹配时列出候选供用户点选。
   - 用户确认不绑定或未查询到可用工具时，完全省略 `tools.yaml`。
2. **里程碑设置**：
   - 询问是否创建里程碑。
   - 若创建：挂到哪一章？选项必须来自已扫描的章节列表（可多选）。
   - 询问每章包含几个里程碑及其名称和说明。
3. **课程报告设置**：
   - 询问是否创建课程报告。

用户未明确确认需要里程碑或课程报告时，不得生成对应目录。严禁将普通课堂练习自动升级为里程碑。

---

### 4. 生成规范目录

- 根目录直接包含 `course.yaml`、`chapters/`，以及可选的 `course-report/`。
- 仅生成数据契约允许的目录和文件，不在根目录添加 README、说明文档、清单副本或外层包装 ZIP；页面素材保留用户提供的附件（包括 ZIP）。
- 所有有序目录和文件使用从 `001` 开始、连续且唯一的三位编号（如 `001-intro/`、`001-cover.png`）。
- YAML、`.prompt.md` 和 `.link` 使用 UTF-8；YAML 只写入数据契约规定的合法字段。
- **纯 ASCII 文件名强约束**：所有素材、页面图片、任务与报告模板的文件名（去除 `NNN-` 前缀后）**必须仅由纯 ASCII 字符（`[a-zA-Z0-9._-]`）组成，严禁包含中文或非 Latin-1 字符**（防止在模板克隆时 OSS CopyObject 的 HTTP 请求头因非法字符被 Node 客户端拦截抛错）。若用户提供的原始文件名为中文，自动重命名为英文语义短名、拼音或时间戳（如 `demo-video.mp4` 或 `export-1781076721832.mp4`），并严格保留真实扩展名。
- 页面素材必须放入同章对应页面编号的 `materials/NNN/`；不能创建没有对应页面的素材目录。
- 任务及报告模板文件可选；有真实 PDF、DOCX、PPTX 或 XLSX 时保留原始文件，无文件时仅生成描述性配置，不伪造空文件或占位文件。

---

### 5. 完成检查与打包

🔴 **CHECKPOINT · 🛑 STOP 3: 打包前结构与元数据校验**

检查目录和编号连续性、必填字段、素材与页面对应关系、**全部文件名纯 ASCII 规范**、工具 ID 合法性，以及是否存在未知文件。若存在非 ASCII 字符文件名必须先行完成重命名。

满足全部约束后，在模板目录旁生成同名 `.zip`。保留原目录，ZIP 文件内必须满足：

- `course.yaml` 直接位于 ZIP 根目录；不得额外包装一层课程目录。
- 仅包含契约允许的文件和目录；排除 `.DS_Store`、`__MACOSX/`、README、临时文件及隐藏文件。
- 条目名称为 UTF-8、NFC、相对路径，并统一使用 `/` 作为分隔符；不含绝对路径、空路径段、`.`、`..`、反斜杠逃逸或符号链接。
- 使用标准 ZIP 2.0（仅 stored 或 deflate）；不使用 ZIP64、加密条目、data descriptor 或未知压缩算法。
- 每个文件的 CRC、压缩大小和解压大小必须在 local header 与 central directory 中保持一致；不得设置 ZIP general-purpose flag 的加密位（bit 0）或 data-descriptor 位（bit 3）。

当前环境缺乏合规打包能力时，停止并向用户说明限制，保留生成目录，不得伪造或声称生成了合规 ZIP。不要调用导入接口或上传 ZIP。

## 异常与失败恢复（Fallback 矩阵）

| 异常场景 | 触发条件 | 一线恢复动作 | 终极兜底策略 |
|---|---|---|---|
| Origin 变量未就绪 | `XAI_PAYLOAD_ORIGIN` 为空 | 提示用户三选一（填 URL / 指定配置文件 / 跳过查询） | 若跳过查询，工具不绑定；课程系列提示手动输入已有系列，禁止默认创建 |
| 系列接口访问失败 | curl `/v1/catalog/series` 报错或超时 | 重试一次并校验 Origin URL 连通性 | 提示用户接口不可达，提供手动输入已有系列名称选项，强调禁止新建 |
| 系列列表为空 | 接口返回 `data.items` 长度为 0 | 确认当前后端环境数据库是否为空 | 向用户如实报告当前无可用系列，询问是否授权明确新建首个系列并确认名称 |
| 工具接口访问失败 | curl `/v1/course-tools` 报错或超时 | 重试一次并检查服务状态 | 提示用户跳过工具查询，本课程模板省略 `tools.yaml` |
| 包含非 ASCII 文件名 | 素材/图片/模板文件名含中文或特殊字符 | 自动重命名为拼音、语义短名或时间戳纯 ASCII 文件名 | 若用户明确禁止重命名，停止打包并报告合规阻断原因 |
| ZIP 打包环境受限 | 系统缺失合规 zip 命令或脚本执行失败 | 调用 Node/Python 原生环境内置压缩逻辑 | 保留规范目录，告知目录路径及打包工具缺失，不交付损坏 ZIP |

## 反例与黑名单（禁止动作）

| # | 禁行反模式 | 危害后果 | 正确规范 |
|---|---|---|---|
| 1 | **自动推导或默认创建课程系列** | 导致数据库滋生未治理的重复/碎片系列，破坏平台元数据一致性 | 必须通过 `/v1/catalog/series` 查询已有系列，强制用户点选；除非用户明确指明新建，否则禁止创建 |
| 2 | **遇用户指令“全默认”时顺带默认系列** | 绕过用户确认壁垒，在导入时隐式在后端新建系列 | 必须进行拦截，明确告知课程系列禁止默认创建，必须从现有列表中选择 |
| 3 | **在 course.yaml 写入 seriesId** | 破坏 ZIP 跨环境迁移能力，导致目标环境因 ID 找不到报错 | 必须且仅允许写入 `seriesName`，由服务端导入事务完成匹配或新建 |
| 4 | **素材或模板文件名包含非 Latin-1/中文** | 触发 OSS CopyObject 标头校验异常，导致克隆或导入失败 | 所有文件（去 `NNN-` 前缀后）必须符合 `^[a-zA-Z0-9._-]+$` 纯 ASCII 规范 |
| 5 | **未经确认自动生成里程碑或课程报告** | 强加评测负担，污染教学目录，篡改教案意图 | 必须在 `🔴 CHECKPOINT` 显式获得用户同意后方可创建相应目录 |
| 6 | **虚构素材文件或更改后缀占位** | 导致二进制内容损坏或损坏文件流传 | 无真实素材时不生成虚构附件，只保留描述性任务配置 |
| 7 | **生成 ZIP 后私自调用导入接口** | 越权操作，违反 skill 职责边界（只负责生成与打包） | 生成同名 ZIP 后交付路径，不调用任何导入或上传接口 |
